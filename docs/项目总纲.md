# 项目总纲

工行杯 · 金融安全服务方向 · 票据不说谎

本文是 PPT 的骨架，也是判断"做到哪了"的依据。
**已验证**的写数字，**待验证**的明确标注，不混在一起。

---

## 一、目的

### 要解决的问题

票据是资金流出的起点。企业报销、商户对账、个人记账，第一步都是把纸质票据上的
数字读进系统。这一步现在有两个缺口：

1. **识别错误是静默的。** OCR 只做文字识别，不判断票据自身的算术是否成立。
   读错一个数字后，输出的 JSON 格式完好、数量级合理，不对照答案看不出来。
2. **识别错误与人为篡改无法区分。** 系统看到一个数字，无从判断它是识别偏差
   还是有人改过票据。报销风控真正关心的是后者。

### 一个亲历的失败，决定了整个设计

早期版本把算术约束写进提示词，要求模型保证 `商品行 − 折扣 = 小计`。

结果：模型读错一个数字后，**为满足这条约束又改写了第二个数字**，产出一份自洽
但错误的结果。所有一致性检查都通过，错误完全隐形。

这不是模型不听话，是约束下的最优解——给它一个必须满足的等式，凑平比读准更容易。

由此确立铁律：**所有校验只在代码侧执行，从不写入提示词。**
模型永远不知道自己正在被什么标准检查，也就无法朝那个标准编数字。

## 二、框架

```
票据图像
   ↓
[大模型]  只做逐行转写。明确禁止加减、核对、调平任何总额
   ↓
JSON：商品行 / 折扣行（含标签） / 小计 / 舍入 / 付款行
   ↓
[Python]  所有求和在此完成
   ↓
三条相互独立的算术约束交叉验证
   ↓
[多次识别投票]  消除单次识别的随机误差
   ↓
结构化账本 + 核验报告（标出存疑票据及失败的是哪一条）
```

### 三条校验

| | 约束 | 单独能抓到什么 |
|---|---|---|
| 一 | 付款行 = 小计 + 税费 + 服务费 − 折扣 + 舍入 | 付款金额被改大 |
| 二 | 商品行总额 − 折扣 = 小计 | 单品价格被改，且付款行仍闭合 |
| 三 | 折扣标签自带金额 = 金额栏 | 折扣金额读错（港式票据专有） |

**为什么必须是三条而不是一条。** 校验一看不见折扣和商品行；校验二看不见付款行；
校验三只在标签带金额时可用。已验证的两个篡改样本正好各被一条抓到：
付款行改动只有校验一发现，单品改动只有校验二发现。

**校验三是一个免费的校验位。** 港式超市折扣行常把金额写进标签本身
（`Buy 3 Save $9.8`、`MB APP UPGRADE -$10`），一个数字在同一行印了两遍。
模型只被要求照抄标签文字，不知道它正被用来交叉验证。

## 三、流程

### 运行时流程（产品）

1. 上传票据照片
2. 每张独立识别 N 次，全部请求打包进一次并发批处理
3. 每次识别在 Python 侧求和，算出三条校验的差额
4. 按证据强弱排序：自洽的优先，标签印证多的优先，最后多数投票
5. 输出账本 + 核验报告

### 验证流程（实验）

| 实验 | 数据 | 测什么 | 状态 |
|---|---|---|---|
| E0 金额归一化 | 构造用例 | 跨地区金额写法能否正确解析 | **已完成 18/18** |
| E1 标注自洽率 | CORD 34 张 | 公开票据本身有多少是自洽的（误报基线） | **已完成** |
| E2 抽取准确率 | CORD 100 张 | 模型读出的字段与标注是否一致 | 待跑 |
| E3 篡改检出 | CORD 自洽子集 | TPR / FPR | 待跑 |
| E4 定性演示 | 港式票据 3 张 | 篡改视觉上不明显，算术躲不掉 | 样本已生成，待送检 |

- **整块重绘**，按框高匹配字号取背景墨色，全自动跑 100 张，出统计量
- **字形复制**，从同票取同字体数字合成，视觉真实，只做 3 张港式票据当配图

## 五、意义

### 对金融安全方向

赛道要的是"用技术守护资金安全"，落点在**多模态模型检测**与**数字防火墙**。
本作品把凭证真伪做成资金流出的第一道关口：不是判断图像有没有被 PS，
而是判断票面数字自己讲不讲得通。

### 技术上的三点

**一、校验不进提示词。** 这是从一次真实失败里换来的。凡是告诉模型的约束，
模型就有动力去满足它而不是读准——约束必须在模型之外执行。

**二、冗余信息是免费的校验位。** 票据为了人看得懂，本来就重复记录了同一笔钱：
小计与商品行、标签与金额栏。人眼忽略的冗余，正是机器可用的交叉验证。

**三、诚实报告误报。** 公开数据上已经测出约 19% 的票据本身就不自洽
（voucher 记法、商品行未标全）。实验必须同时报 TPR 和 FPR。
只报检出率的作品，评委一问就穿。

### 固有边界

查的是**票面算术是否自洽，不是像素取证**。造假者若把商品行、小计、付款行
一并改成彼此吻合的数字，三条校验都会通过。

本方法提高的是伪造成本：改一个数字要同时骗过三条相互独立的约束，
远难于改动单处。这个边界要主动写进 PPT，不等评委问。
