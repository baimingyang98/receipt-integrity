# 演示界面

只用 Python 标准库，不需要安装任何东西。

```
python app/server.py
```

浏览器打开 <http://localhost:8765>。

## 模型密钥

二选一：

- 设置环境变量 `DEEPSEEK_API_KEY`
- 在仓库根目录新建 `.env`，写一行 `DEEPSEEK_API_KEY=你的密钥`（`.env` 已在 `.gitignore`，不会被提交）

没有密钥时页面只能「回放」。

## 两种来源

- **实时识别**：把图片发给模型，默认独立识别 3 次（并行），用与实验完全相同的提示词与判定规则
- **回放**：读 `app/cache/` 里之前那次真实识别的模型原始输出，重新跑一遍判定。页面标明识别时间。
  用于现场网络或接口出问题时——展示的仍是真实结果，不是编造的数据

## 示例单据（`app/examples/`）

| 示例 | 预期 | 出处 |
|---|---|---|
| 港式超市小票 | 可信，折扣标签印证 | 作者本人票据 |
| CORD 36 原图 / 税额被改 | 可信 / 存疑（校验一） | CORD validation；实验中对照 B 把改后的 1,427 读成 1,727 |
| CORD 23 付款被改 | 存疑（校验四） | CORD validation；实验中对照 B 以"无找零行"跳过付款核对 |
| 商业发票 原图 / 第 2 行金额被改 | 可信 / 存疑（行内两条 + 行金额之和） | katanaml 合成发票 |

篡改图用与实验相同的方法生成（同一字段、同样的改动）；CORD 原图取自 HF 在线接口，
可能经过重新压缩，不保证与实验时的图逐像素相同。

## 路演前检查

1. 用实时识别把 6 个示例各跑一次，生成回放缓存（示例上会出现「可回放」标记），提交 `app/cache/`
2. 断网后切到「回放」，确认 6 个示例都能显示
3. 投影分辨率下（1280 或 1920 宽）看一遍排版
